# Employee Management System

A Python-based Employee Management System designed to manage employee information efficiently using a simple and user-friendly command-line interface.

## Features

* Add new employees
* View employee details
* Search employees by ID
* Search employees by name
* Search employees by salary
* Search employees by department
* Compare employee salaries
* Update employee information
* Delete employee records
* Permanent data storage using JSON
* Handles employee records through a simple command-line interface

## Technologies Used

* Python
* JSON
* Object-Oriented Programming
* File Handling
* Data Validation

## Project Structure

```text
employee-generation-system/

├── employee_management.py

```

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/abhinayapodakatla/employee-generation-system.git
```

### 2. Open the project folder

```bash
cd employee-generation-system
```

### 3. Run the application

```bash
python employee_management.py
```

## Data Storage

Employee information is stored permanently in the `employees.json` file. The application reads and updates this file whenever employee records are added, modified, or deleted.

This project was developed to practice Python programming, file handling, data management, and GitHub project management.
